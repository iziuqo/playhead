# Prototype latency spike (dev plugin)

Builds a one-octave piano in a Figma Design file using only prototype features:
each key has a video fill (a note's sound + glow) and plays on mouse-down or on
its computer key (A–K). Used to compare no-code prototype latency with the Make app.

Regenerate `code.js` with the build steps in the project thread, then in Figma desktop:
Plugins → Development → Import plugin from manifest… → pick `manifest.json` → run it.
